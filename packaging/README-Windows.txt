PDF Editor for Windows
=====================

Thank you for using the PDF Editor! This is a small, self-contained
program that lets you read, annotate, and edit PDF documents.

What's in this folder
---------------------
  PDF Editor.exe   The program. Double-click it to run.
  pdfium.dll       A required helper file. Keep it next to PDF Editor.exe.

How to run it
-------------
1. Copy this whole folder to a place you can find easily (for example,
   your Desktop or Documents folder). Keep the two files together.
2. Double-click "PDF Editor.exe".
3. The first time, Windows may show a "Windows protected your PC"
   (SmartScreen) warning because this program is not signed. If it does:
       - Click "More info"
       - Click "Run anyway"
   This is normal for programs shared this way and is safe.

How to open a PDF
-----------------
  - Click the "Open" button (or press Ctrl+O), then choose your PDF.

What you can do
---------------
  - Read and search PDFs (Ctrl+F to search)
  - Highlight and draw on pages (the annotation tools)
  - Edit the actual text (the "Edit text" tool)
  - Add, delete, rotate, and reorder pages
  - Save your changes (Ctrl+S)

Need help?
----------
If something doesn't work, please let the person who gave you this
program know, and tell them what you were doing and what happened.

Note: text editing works with standard English letters and numbers.
Other languages may not edit correctly yet.
